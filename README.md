# NEXO · Prototipo Web 1.1

Sitio estático con `index.html` (portada) y `laboratorio.html` (demostración).

## Publicar gratuitamente en GitHub Pages
1. Crear un repositorio público nuevo en GitHub (sin datos privados).
2. Subir únicamente `index.html`, `laboratorio.html` y este README a la raíz.
3. En Settings → Pages → Build and deployment, elegir Deploy from a branch, rama `main`, carpeta `/ (root)`.
4. Esperar la publicación y abrir la dirección que GitHub muestre.

También puede desplegar la carpeta estática en Cloudflare Pages o Vercel según las condiciones de sus planes gratuitos.

## Privacidad y límites
- Los archivos elegidos en el laboratorio se previsualizan en el navegador mediante URL.createObjectURL y no se transmiten.
- No existe OCR, evaluación automática ni conexión a Google Workspace.
- No cargar ni publicar manuscritos reales en repositorios públicos.
- La aplicación real requerirá autenticación, permisos institucionales, almacenamiento privado y backend.
