Contraste matemático

Para x ≠ 1, se cumple f(x) = x + 1. Al aproximarse x a 1 por ambos lados, f(x) se acerca a 2.

limx→1⁻ f(x) = limx→1⁺ f(x) = 2.

El límite existe aunque f(1) no está definida.
