Verificación fundamentada

Hallazgo · Simplificación algebraica

Se identifica una cancelación incorrecta. El numerador se factoriza como (x − 3)(x + 3).

Corrección verificable

(x² − 9)/(x − 3) = x + 3, para x ≠ 3.

Pregunta para la defensa

¿Por qué debe conservarse la condición x ≠ 3 después de simplificar?
